# Security

Do not attach your `%LOCALAPPDATA%\EbatVlastey` directory to public reports. It contains the Windows user identifier and recovery data.

Report a security issue through GitHub's private vulnerability reporting, when enabled on this repository. Include the application version, Windows build, reproduction steps and effect, without credentials, private keys or personal certificate inventories.

Version 0.1.0 is a preview. The clean Windows 10/11 installation/recovery matrix is not complete. See docs/testing.md. The project does not promise compatibility with every application, cryptographic provider or custom trust store.
