# EbatVlastey

EbatVlastey ограничивает доверие Windows к двум корневым сертификатам Минцифры. Сертификаты, выданные через эти центры, разрешаются только для сайтов в **.ru, .su и .рф**. Для прямых IP-адресов они отклоняются. Другие центры сертификации программа не меняет.

**Версия 0.1.2 предварительная.** Установка, отказ в предупреждении Windows и восстановление на чистых Windows 10/11 ещё не прошли полную проверку. Выполненные тесты и оставшиеся сценарии перечислены в [статусе испытаний](docs/testing.md).

Программа предназначена для Windows 10 22H2 x64 и Windows 11 x64. Изменения затрагивают только текущего пользователя; права администратора не нужны. Совместимость с Windows 10 ещё требует проверки. Действующий статус поддержки Windows и .NET указан в [таблице Microsoft](https://learn.microsoft.com/en-us/dotnet/core/install/windows#supported-versions).

## Скачать и использовать

1. Откройте [Releases](https://github.com/MiniBeary/EbatVlastey/releases).
2. Выберите выпуск 0.1.2 и скачайте `EbatVlastey-win-x64.exe`. Через «Code → Download ZIP» можно скачать исходники; готовый файл находится в Releases.
3. Запустите `.exe` обычным способом, без «Запуск от имени администратора».
4. Нажмите «Установить». Программа сохранит резервную копию, создаст сертификаты с ограничением доменов и проведёт проверки.
5. Windows попросит подтвердить установку корня «EbatVlastey Restricted RU Root …». Подтвердите запрос, если сами запустили эту установку. Отказ отменяет операцию.
6. Дождитесь сообщения об успешной установке. Затем полностью закройте и снова откройте Chrome и Edge.

Программа запускается из скачанного файла. Все необходимые для её работы компоненты включены в `.exe`.

Файл не подписан цифровой подписью, поэтому Windows может показать неизвестного издателя или предупреждение SmartScreen. Если запуск запрещён политиками компьютера, не отключайте защиту ради установки. Исходники доступны для проверки и самостоятельной сборки.

Рядом с `.exe` опубликован файл `SHA256SUMS.txt`. Откройте PowerShell в папке со скачанным файлом и выполните:

```powershell
Get-FileHash .\EbatVlastey-win-x64.exe -Algorithm SHA256
```

Сравните полученную сумму со строкой в `SHA256SUMS.txt`. Совпадение подтверждает соответствие файла опубликованной сумме. Цифровую подпись издателя такая проверка не заменяет.

## Кнопки

| Кнопка | Что делает |
|---|---|
| Установить | Создаёт сертификаты с ограничением доменов и устанавливает их для текущего пользователя. Исходные сертификаты Минцифры заранее устанавливать не нужно. |
| Проверить | Проверяет сохранённые файлы, записи в хранилищах Windows и ограничения доменов. Браузеры не запускает. |
| Восстановить | Возвращает состояние, сохранённое перед установкой. |
| Проверить сайты | Проверяет HTTPS-соединение со Сбербанком, Госуслугами, страницей Госключа и example.com. Вход и подписание документов не проверяет. |
| Открыть резервную копию | Открывает папку с журналом и файлами восстановления. |

При установке программа проверяет цепочки Windows без интернета. Если найдены Chrome или Edge, она запускает их с временными профилями и проверяет сертификаты через локальный HTTPS-сервер. Ваши обычные профили браузеров в этой проверке не участвуют. После установки временные секретные ключи проверки уничтожаются. Если оба браузера отсутствуют, в журнале будет указано, что проверено только доверие Windows.

«Проверить сайты» требует интернет-соединения. Недоступность сайта может быть вызвана сетью, блокировкой или самим сайтом и не доказывает ошибку сертификата.

Кнопка «Проверить» использует журнал `manifest.json`, который создаётся при установке. Если нажать её до установки, программа сообщит, что журнал не найден. Если файл пропал после установки, сохраните остальные файлы резервной копии.

## Восстановление и резервная копия

Если обязательная проверка завершится ошибкой, программа попытается автоматически вернуть прежнее состояние. После аварийного завершения она запустит восстановление при следующем запуске. Если восстановление не удалось, сохраните резервную копию и повторите «Восстановить».

Файлы восстановления находятся в `%LOCALAPPDATA%\EbatVlastey` и привязаны к пользователю Windows. Открыть папку можно кнопкой «Открыть резервную копию».

Не удаляйте эту папку до восстановления и не публикуйте её содержимое в GitHub Issues. В журнале есть идентификатор пользователя Windows (SID) и сведения о затронутых сертификатах.

Восстановление возвращает записи, которые изменила программа. Если исходных сертификатов до установки не было, программа не добавит их при восстановлении. Предыдущие завершённые операции сохраняются в подпапке `history`.

Чтобы убрать ограничение, нажмите «Восстановить» и дождитесь завершения операции. После этого можно удалить `.exe`. Само удаление файла программы не отменяет изменения в хранилищах Windows.

Если файл программы потерян, скачайте версию 0.1.2 повторно и запустите её под тем же пользователем Windows. Она может использовать сохранённую резервную копию, в том числе созданную версиями 0.1.0 и 0.1.1.

## Как работает ограничение

При установке программа создаёт отдельный корень доверия и новые версии сертификатов Минцифры с сохранением их публичных ключей. В сертификаты добавляются ограничения доменов. Исходные пользовательские корни сохраняются в резервную копию и удаляются из доверенного хранилища.

Для каждой новой установки создаётся свой корень. Секретные ключи корня и тестового сервера используются только в памяти и не сохраняются в файлы или хранилища. Программа не отправляет телеметрию, не обновляется автоматически и не скачивает новые доверенные корни.

## Границы действия

- Если доверие к тем же ключам задано для всего компьютера, корпоративной политикой или другим хранилищем Windows, которое программа не может изменить, установка остановится до изменений.
- Ограничение работает в программах, которые используют изменённое доверие Windows и проверяют ограничения имён. Firefox, Яндекс Браузер и программы со своими хранилищами не проверены.
- В зонах .ru, .su и .рф доверие Минцифры сохраняется. Ограничение не гарантирует безопасность отдельных сайтов.
- Работа с ГОСТ-провайдерами, электронными подписями, входом в аккаунты и подписанием документов не проверена. Настройки приложения Госключ на телефоне не меняются.
- Срок новых сертификатов не превышает срок исходных. Текущий комплект действует не дольше 28 февраля 2032 года; после этого понадобится новая версия комплекта.

## Сборка и тесты

Для сборки из исходников нужен .NET SDK 10.0.401 или совместимое обновление, допускаемое настройками `global.json`. Выполните команды из папки проекта:

```powershell
$env:DOTNET_CLI_TELEMETRY_OPTOUT = '1'
$env:DOTNET_GENERATE_ASPNET_CERTIFICATE = 'false'
dotnet run --project tests/EbatVlastey.Tests -c Release -- --browsers
./scripts/build.ps1
```

Готовые файлы появятся в `artifacts`. Тесты проверяют цепочки Windows с отдельным доверенным корнем в памяти. Установка и восстановление испытываются в отдельном тестовом хранилище; рабочие хранилища сертификатов тесты не меняют.

Для проверки готового `.exe` предусмотрены команды:

- `--self-test --report <путь.json>` проверяет цепочки в памяти без установки сертификатов.
- `--ui-smoke` открывает интерфейс и автоматически закрывает его без изменения сертификатов.

GitHub Actions запускает тесты и собирает `.exe`. Теги `v*` публикуются как предварительные выпуски. Для обычного выпуска нужно завершить [испытания на чистых Windows 10 и 11](docs/testing.md).
