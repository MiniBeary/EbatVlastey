# Статус проверки 0.1.1

Выполнены следующие автоматические проверки:

- генерация независимых корней; сохранение исходных RSA/ГОСТ публичных ключей;
- реальные цепочки Windows в режиме CustomRootTrust: `.ru`, `.su`, `.рф` принимаются; `.com`, ложное окончание, смешанные SAN, IPv4 и IPv6 отклоняются ограничениями;
- работа локального TLS-сервера с секретным ключом только в памяти;
- запуск настоящих Chrome/Edge с временными профилями через CDP; неизвестный тестовый корень отклоняется; ошибки сети и неизвестного издателя не засчитываются как ограничения;
- установка/восстановление на отдельном тестовом хранилище с нулём, одним и двумя исходными корнями;
- отказ записи на каждом этапе, сбой браузерной проверки, прерванная установка, повреждение артефактов, повреждение резервных копий, неверный пользователь и повторные операции;
- обнаружение одного RSA-ключа при отсутствующем NULL и вариантах RSA-OAEP/RSA-PSS: отказ при доверии на уровне компьютера/политик, точное восстановление пользовательского сертификата;
- чтение физических хранилищ Windows без изменений.

Эти проверки **не заменяют** полный тест установки на чистом ПК. Рабочие доверенные хранилища локального разработчика при испытаниях не изменяются.

## Условие обычного выпуска

Для Windows 10 22H2 x64 и Windows 11 x64 выполнить и записать версию ОС, `.exe` SHA-256, результат и ошибки каждого сценария. Перед каждым сценарием возвращаться к снимку чистой виртуальной машины.

| Сценарий | Windows 10 | Windows 11 |
|---|---|---|
| Исходных сертификатов нет; установка; проверка; восстановление до отсутствия | Не проверено | Не проверено |
| Один исходный корень; точное восстановление контекстных свойств | Не проверено | Не проверено |
| Оба исходных корня; точное восстановление | Не проверено | Не проверено |
| Отказ в предупреждении Windows; исходное состояние сохранено | Не проверено | Не проверено |
| Прерывание процесса установки; восстановление при следующем запуске | Не проверено | Не проверено |
| Повторная установка и повторное восстановление | Не проверено | Не проверено |
| Корень на уровне компьютера/политики; остановка без изменений | Не проверено | Не проверено |
| Chrome/Edge принимают разрешённые имена и отклоняют запрещённые | Не проверено | Не проверено |
| Другой центр сертификации продолжает работать | Не проверено | Не проверено |

Проверять реальные хранилища следует только в отдельной тестовой Windows, вручную подтверждая ожидаемые предупреждения. Снимок до теста нужен для сравнения Root/CA и восстановления среды при аварии. Никакой тест не должен отключать проверку TLS или защиту корневого хранилища.

GitHub-hosted Windows Server x64 и Windows 11 ARM64 используются для дополнительных автоматических проверок. Они не подменяют приведённую матрицу Windows 10/11 x64 и не подтверждают интерактивные предупреждения Windows.
