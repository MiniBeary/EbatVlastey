# v0.1.3: предварительная версия

Исправлена безопасность проверки Chrome и Edge. Раньше временный браузер открывал локальный порт управления без проверки учётной записи клиента. Другой пользователь того же ПК мог подключиться к нему во время установки и использовать права запущенного браузера. Теперь управление идёт через приватные наследуемые дескрипторы канала; порт отладки не открывается. При ошибке канала установка отменяется с восстановлением прежнего состояния.

Регрессионный тест обнаруживал открытый порт до исправления. В версии 0.1.3 Chrome и Edge работают без портов управления IPv4/IPv6. Проверены успешная локальная навигация, отказ для неизвестного корня, передача сообщений канала, ограничение наследования дескрипторов и очистка профиля после ошибки запуска.

Самостоятельный `.exe` для 64-разрядной Windows. Русский интерфейс: установка ограниченного доверия Минцифры, проверка, восстановление и диагностика HTTPS-сайтов.

Разрешены только .ru, .su и .рф; прямые IP запрещены. Работа только с текущим пользователем, без администратора. На каждом ПК создаётся отдельный корень, секретные ключи не сохраняются.

Для обновления замените `.exe` и запустите его под тем же пользователем Windows. Повторная установка сертификатов не требуется. Формат резервной копии совместим с версиями 0.1.0, 0.1.1 и 0.1.2.

Проверены запуск опубликованного `.exe`, 11 встроенных проверок сертификатов и 26 автоматических тестов, включая восстановление и сбои в тестовом хранилище. Рабочие сертификаты при проверке не менялись.

Ранее получен пользовательский отчёт об успешной установке на Windows 10 без исходных сертификатов Минцифры. Версия `.exe` в отчёте не указана. Полная установка новой версии на Windows 10, атака из второй учётной записи и полный набор сценариев на чистых Windows 10/11 отдельно не проверены: [статус испытаний](https://github.com/MiniBeary/EbatVlastey/blob/main/docs/testing.md).

Файл не подписан цифровой подписью. SHA-256 приложен отдельно. Скачайте EbatVlastey-win-x64.exe; все необходимые компоненты включены в файл.

До первого использования прочитайте [инструкцию](https://github.com/MiniBeary/EbatVlastey#readme). Не удаляйте резервную копию до восстановления. Собственные хранилища программ и подписание документов требуют отдельных проверок.
