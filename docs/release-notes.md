# v0.1.2 — предварительная версия

Если нажать «Проверить» до установки, программа сообщает: «Проверка недоступна: журнал установки не найден». Раньше появлялась английская ошибка с путём к `manifest.json`. Добавлен тест этого случая: сертификаты не изменяются, журнал установки не создаётся.

Формат резервной копии совместим с версиями 0.1.0 и 0.1.1. Для перехода на 0.1.2 достаточно запустить новый `.exe` под тем же пользователем Windows; повторная установка не требуется.

Самостоятельный `.exe` для 64-разрядной Windows. Русский интерфейс: установка ограниченного доверия Минцифры, проверка, восстановление и диагностика HTTPS-сайтов.

Разрешены только .ru, .su и .рф; прямые IP запрещены. Работа только с текущим пользователем, без администратора. На каждом ПК создаётся отдельный корень, секретные ключи не сохраняются.

Проверены запуск опубликованного `.exe`, 11 встроенных проверок сертификатов и 20 автоматических тестов, включая восстановление и сбои в тестовом хранилище.

Получен пользовательский отчёт об успешной установке на Windows 10. До установки исходных сертификатов Минцифры на этом ПК не было. Chrome и Edge приняли разрешённые домены и отклонили запрещённые; Сбербанк, Госуслуги и example.com доступны по HTTPS. Версия проверенного пользователем `.exe` в отчёте не указана. Полный набор сценариев на чистых Windows 10/11 ещё не пройден: [статус испытаний](https://github.com/MiniBeary/EbatVlastey/blob/main/docs/testing.md).

Файл не подписан цифровой подписью. Список SHA-256 приложен отдельно. Скачайте EbatVlastey-win-x64.exe; устанавливать отдельные runtime не требуется.

До первого использования прочитайте [инструкцию](https://github.com/MiniBeary/EbatVlastey#readme). Не удаляйте резервную копию до восстановления. Собственные хранилища программ и подписание документов требуют отдельных проверок.
