# v0.1.1 — предварительная версия

Исправлена ошибка v0.1.0: сертификат с тем же RSA-ключом мог быть пропущен, если иначе записаны параметры алгоритма. Теперь учитываются отсутствующий NULL и варианты RSA-OAEP/RSA-PSS; добавлены проверки отказа при доверии на уровне компьютера/политик и точного восстановления пользовательских сертификатов. Используйте v0.1.1 вместо v0.1.0. Формат резервной копии совместим.

Самостоятельный `.exe` для 64-разрядной Windows. Русский интерфейс: установка ограниченного доверия Минцифры, проверка, восстановление и диагностика HTTPS-сайтов.

Разрешены только .ru, .su и .рф; прямые IP запрещены. Работа только с текущим пользователем, без администратора. На каждом ПК создаётся отдельный корень, секретные ключи не сохраняются.

**Не заявляется как полностью проверенный обычный выпуск.** Проверены цепочки Windows в памяти и логика восстановления на отдельном тестовом хранилище. Полная установка/отмена предупреждения/восстановление на чистых Windows 10 и 11 x64 ещё не проверены: [матрица](https://github.com/MiniBeary/EbatVlastey/blob/main/docs/testing.md).

Файл не подписан цифровой подписью. Список SHA-256 приложен отдельно. Скачайте EbatVlastey-win-x64.exe; устанавливать отдельные runtime не требуется.

До первого использования прочитайте [инструкцию](https://github.com/MiniBeary/EbatVlastey#readme). Не удаляйте резервную копию до восстановления. Собственные хранилища программ и подписание документов требуют отдельных проверок.
